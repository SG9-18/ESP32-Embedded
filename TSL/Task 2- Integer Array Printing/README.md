# Task 02 – Integer Array Printing

## Objective

Create an integer array using the ESP32 and print each element of the array on a separate line through the Serial Monitor.

## Task Details

| Parameter | Details        |
| --------- | -------------- |
| Task      | 02             |
| Date      | 15 May         |
| Mode      | Online         |
| Platform  | ESP32          |
| Framework | Arduino        |
| IDE       | PlatformIO     |
| Output    | Serial Monitor |

## Concept Covered

* Integer arrays
* Array indexing
* `for` loop
* Serial communication
* Serial Monitor output

## Working

An integer array is initialized in the ESP32 program. A `for` loop is used to access each array element sequentially and print it on a separate line through the Serial Monitor.

## Expected Output

```text
10
20
30
40
50
```

*The actual values depend on the array defined in the program.*

## Tools Used

* ESP32
* VS Code
* PlatformIO
* Serial Monitor

## Learning Outcome

This task demonstrates basic array handling and iteration in an embedded C/C++ program while reinforcing the use of serial output for monitoring and debugging.
